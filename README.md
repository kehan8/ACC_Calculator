# ACC Calculator

A calculator for the Roblox game **Anime Card Collection**.

**Live site:** https://kehan8.github.io/ACC_Calculator/

## Pages
- **Conveyor Calculator** – enter your income per second and pick your 6 conveyor packs.
  It shows which rarities are profitable and your net income after AutoBuy.
- **Fish Exchange** – enter your fish per rarity and see how many you still need
  to trade up to Rainbow.

## Features
- Works on both pages with one shared style
- Dark mode toggle (🌙/☀️), your choice is remembered
- No install needed – plain HTML, CSS and JavaScript

## Updates
The data is updated every week when new packs come out.
